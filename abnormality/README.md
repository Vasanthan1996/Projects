# 🏭 Manufacturing Anomaly Detection System

A comprehensive machine learning and deep learning based tool for abnormality/outlier detection in manufacturing quality control data.

## ✨ Features

- **Mixed Data Handling**: Supports numeric values, text annotations, and missing values
- **Per-Item Modeling**: Separate models for each product type (item code)
- **Multiple Algorithms**: Supports both ML and DL algorithms with ensemble methods
- **Interactive Dashboard**: Streamlit-based web interface with real-time updates
- **Feedback Integration**: Continuous learning from user feedback
- **Comprehensive Visualizations**: Interactive charts using Plotly
- **Database Integration**: SQLite for storing feedback and audit logs
- **Export Capabilities**: Export results in CSV, Excel, and JSON formats
